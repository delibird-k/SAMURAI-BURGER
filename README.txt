## 後から変更する場所

### 開催場所の画像
`index.html` の ACCESS セクションにある `place-placeholder` を画像タグに変更。

例:
<img src="images/place.jpg" alt="開催場所">

### 問い合わせメール
CONTACT セクションの `contact-placeholder` を変更。

例:
<a href="mailto:example@example.com">example@example.com</a>
